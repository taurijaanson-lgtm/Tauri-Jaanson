# Tallinna Õigusbüroo – uus veebileht

Üks iseseisev `index.html` (pole build-sammu). Ava brauseris või laadi üles serverisse.

Sisu põhineb praegusel tallinnlaw.ee lehel (avaleht, teenused, kontakt, lingid).

## Üle vaadata enne avaldamist
- Postiindeks: vanal lehel on nii 10115 kui 10145 – uuel on 10115.
- Faks ja pangarekvisiidid (Eesti Ühispank) jäeti välja kui aegunud.
- Vanad lingid (Hansapank, Sampo, ESTLEX, eer.ee, ma.ee, nc.ee) asendati kehtivatega.
- Kontaktvorm avab kasutaja e-postiprogrammi (mailto); serveripoolse saatmise jaoks on vaja vormiteenust.
- EN/RU versioonid on veel tegemata.
